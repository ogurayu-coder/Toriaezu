# 🐾 わんこノート

犬の体調・お世話を記録するシンプルなWebアプリです。ごはん・散歩・うんち・お薬・気になったことを、その場でサッと記録できます。特にシニア犬や持病のある子の「あのとき何があったか」を後から見返せるようにする目的で作っています。

アプリはブラウザだけで動作します。`demo.html`の記録はその端末の中(localStorage)だけに保存されます(`index.html`はクラウド同期版で、後述の通り例外です)。

---

## ファイル構成

| ファイル | 用途 | URL |
|---|---|---|
| `demo.html` | **みんなが使うメインの版。** 自分の犬の記録を、自分の端末に保存します | https://ogurayu-coder.github.io/Toriaezu/demo.html |
| `index.html` | Moのクラウド同期版。旅行中など、Moと獣医さんが記録を共有する必要があるときだけ使います | https://ogurayu-coder.github.io/Toriaezu |

`index.html`と`demo.html`は保存先のキー名が別々になっているため、同じ端末で両方開いてもデータが混ざることはありません。

### ⚠️ `index.html`について(重要)

`index.html`はクラウド(Firebase)に同期する版で、**旅行中にMoと獣医さんが記録を共有するためだけに使うものです。記録は必ず`demo.html`を使ってください。** `index.html`に書き込むとMoのクラウド上のデータに直接影響するため、旅行中にMoの獣医さんが記録するとき以外は書き込まないようにしてください(見るだけなら問題ありません)。

## 💾 データの保存について

**ここから先は`demo.html`(みんなが使うメインの版)についての説明です。`index.html`はクラウドに同期するので対象外です(上記参照)。**

- 記録は**そのブラウザ・その端末の中(localStorage)**だけに保存されます。他の端末やクラウドとは自動で共有されません。
- 同じURLでも、端末が違えば(例:iPhoneとiPad、スマホとパソコン)、別々のデータとして扱われます。
- ホーム画面にアイコンを追加しておくと、毎回同じ場所からアクセスできて安心です。

**📱 iPhone(Safari)の場合**
- プライベートブラウズモードで開くと、タブを閉じた瞬間にデータが消えます。普段使いは必ず通常モードのSafariで。
- 「設定」→「Safari」→「履歴とWebサイトデータを消去」を行うと、その端末のローカル記録は完全に消えます。復元手段が無いため、ストレージ整理や不具合対応でこの操作をする際は必ず先にバックアップを取ってください。

**🤖 Androidの場合**
- Chromeなどのシークレットモードで開くと、iPhoneと同様にタブを閉じた瞬間にデータが消えます。
- ブラウザの設定から「閲覧データを削除」(Cookieとサイトデータを含む)を行うと、同じくローカル記録が完全に消えます。こちらも操作前に必ずバックアップを。

## Moが旅行するとき

Moが旅行中は`index.html`(クラウド同期版)を使います。Moと獣医さんが同じURL(`index.html`)を開くと、Firebase経由で記録が自動的に同期されるので、その都度バックアップをコピー&ペーストする必要はありません。旅行が終わったら、ふだん使いの`demo.html`に戻ります。

**この方法はMo専用です。**

---

## バックアップ

アプリ内の「バックアップを表示」から、記録+犬のリストをまとめてテキストとして書き出せます。「コピーする」ボタンを押すだけでコピーできるので、メモアプリなどに保存しておくと安心です。「バックアップを復元」に貼り付ければ元に戻せます。

**犬を追加・削除する前や、iPhoneの「Webサイトデータを消去」をする前は、必ずバックアップを取っておいてください。**

### 機種変更・端末を買い替えるとき

localStorageは端末ごとのデータなので、新しい端末に自動的には引き継がれません。機種変更の前に必ず以下の手順でバックアップを移してください。

1. 古い端末でアプリを開き、「バックアップを表示」→「コピーする」を押す
2. **自分宛てのメール**を開き、本文にそのまま貼り付けて送信(添付ファイルにしなくてOK。本文にペーストするのが一番確実)
3. 新しい端末で同じメールを開き、貼り付けた内容をコピー
4. 新しい端末でアプリを開き、「バックアップを復元」に貼り付けて復元

このひと手間を踏まないと、新しい端末では記録が空っぽの状態からのスタートになってしまうので注意してください。

## 主な機能

- ごはん・散歩・うんち・お薬・気になったことの記録(時間・メモ付き)
- ワクチン・駆虫の記録と、最終接種日・次回予定日の管理(期限が近いと色で知らせます)
- カレンダー表示(気になったことがあった日が一目でわかる)
- 自由ワードでの検索(例:嘔吐、発作。メモの中身から探せます)
- 過去の日付にさかのぼって記録を追加(カレンダーの日付をタップ)
- バックアップの書き出し・復元
- 「🐾 犬を管理」での犬の追加・編集・削除
